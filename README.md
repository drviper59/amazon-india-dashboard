# Amazon India Sales Dashboard

**Open the live dashboard:** https://drviper59.github.io/amazon-india-dashboard/

Share that link with your internship group. It opens directly in a browser; no install or run commands are needed.

This interactive dashboard summarizes Amazon India order data across sales, profit, order status, product categories, payments, fulfillment, and geography. Use the filters and search controls to explore the data, then export the visible orders as CSV.

The dashboard loads the dataset from the linked Google Sheet when a local CSV copy is not available. The sheet must remain accessible to anyone with the link for the hosted dashboard to refresh its data.

**Source repository:** https://github.com/drviper59/amazon-india-dashboard
